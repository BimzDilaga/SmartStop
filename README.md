# SmartStop

Panduan endpoint, mode demo/API, status integrasi, dan alur tiket–supir: [docs/FRONTEND_API.md](docs/FRONTEND_API.md).

Uji logika frontend: `node --test tests/frontend.test.mjs`. Build: `npm run build`.
